Already enabled in Settings?

macOS can keep an older approval after an app update. If HereWord is already enabled in but setup still asks for approval:

  1. Switch HereWord off and back on. Choose Quit & Reopen if macOS asks.
  2. If setup still cannot confirm access, select HereWord in that permission list and remove it with the minus button. Use the plus button to add /Applications/HereWord.app, then enable it again.
  3. Quit and reopen HereWord. Setup resumes and verifies permissions and shortcut registration before showing Ready.

Use the installed app in Applications. Eject any old installer disk image so you do not approve its copy by mistake.
